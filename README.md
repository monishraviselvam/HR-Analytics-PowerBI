HR Analytics Dashboard using Power BI

 Project Overview
This project analyzes employee demographics, workforce distribution, hiring trends, and employee termination patterns using Power BI.

Project Objectives
- Analyze employee demographics and workforce distribution.
- Understand employee hiring trends.
- Evaluate employee termination patterns.
- Identify department-wise workforce and termination rates.
- Provide data-driven recommendations for HR decision-making.

Tools Used
- Power BI
- DAX
- Power Query

Dataset Description
- Total Records: 22,214
- Total Columns: 14
- Dataset: HR Analytics

Key Performance Indicators
- Total Employees: 22,214
- HQ Work: 75.25%
- Remote Work: 24.75%
- Average Age: 38.43 years
- Active Employees: 18,285
- Terminated Employees: 3,929
- Termination Rate: 17.69%

Project Deliverables
- Interactive Power BI Dashboard
- KPI Analysis Report
- Dashboard Screenshots
- Project Presentation

Key Insights
- Engineering is the largest department.
- Headquarters has the highest employee concentration.
- Overall employee termination rate is 17.69%.
- Auditing has the highest department termination rate at 23%.
- Hiring remained relatively stable across most years.

Recommendations
- Improve employee retention strategies.
- Evaluate remote and office work arrangements.
- Introduce employee training and development programs.
- Improve data-driven recruitment planning.
